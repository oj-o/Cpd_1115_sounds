# 저승공무원으로 취업했습니다!!! — 음향 큐 패키지

공연 당일 노트북 한 대로 운영할 수 있는 오프라인 음향 큐 세트입니다. 인터넷이 없어도 작동합니다.

```
cue_package/
├─ index.html          ← 큐 플레이어 (더블클릭으로 실행)
├─ cues.js             ← 큐 목록 (순서·볼륨·페이드·음원 경로)
├─ audio/              ← 공연용 음원 11개 (직접 작곡·렌더링, 저작권 걱정 없음)
├─ tools/
│   ├─ render_cues.py  ← audio/ 음원을 다시 만드는 Python 스크립트
│   └─ generate_ml.py  ← (선택) ML 모델로 음원을 새로 생성
├─ lighting/           ← 조명 큐: MA dot2 자동 입력 스크립트 (lighting/README.md 참고)
│   └─ cue_maker.html  ← 웹 조명 큐 생성 + 비상 수동 조정 (큐 플레이어 우측 하단 '💡 조명 큐 생성' 버튼)
└─ README.md
```

## 1. 실행

1. 폴더 전체를 공연용 노트북에 복사합니다. `audio/` 폴더가 `index.html` 옆에 있어야 합니다.
2. `index.html`을 **Chrome 또는 Edge**로 엽니다. 상단에 "음원 11개 준비 완료"가 뜨면 준비된 것입니다.
3. 처음 한 번은 화면을 클릭하거나 GO를 눌러야 소리가 나옵니다(브라우저 정책).

| 조작 | 기능 |
| --- | --- |
| `Space` 또는 GO 버튼 | 대기 큐(초록 줄) 실행 후 다음 큐로 이동 |
| `↑` `↓` / 큐 클릭 | 대기 큐 바꾸기 |
| 큐 두 번 클릭 | 그 큐를 바로 실행 |
| 페이드 시간 3초 / 5초 / 10초 버튼, 또는 `3` `5` `0` 키 | 페이드 시간 선택 (마지막 선택을 기억) |
| GO 버튼 / `Space` (소리가 나오는 중) | **GO 버튼 하나로 GO·일시정지·이어서.** 소리가 나오는 동안은 GO 버튼이 노란 "일시정지"로 바뀌어, 누르면 나오는 소리가 모두 멈추고 다시 누르면 이어서 재생됩니다(입장 음악·녹음·효과음·엔딩 모두). 소리가 끝나거나 `F`로 페이드하면 다시 GO. 예외: 벨소리·신호음(1·3·4)이 울리는 동안은 GO가 다음 큐(1B·3B·4B 받음, 4A 녹음)를 실행합니다. 입장 음악이 끝나지 않았을 때 공연을 시작하려면 `F`로 페이드한 뒤 GO. `Shift`+`Space`는 언제나 다음 큐 GO |
| `P` 또는 "일시정지" | 재생 중인 소리를 모두 멈춤. 재생 중 소리 카드의 막대를 누르거나 끌면 그 위치로 이동. 한 번 더 누르면 멈춘 자리에서 이어서 재생 (각 소리 카드의 "멈춤" 버튼으로 하나씩도 가능) |
| `F` 또는 "전체 페이드" | 재생 중인 모든 소리를 선택한 시간 동안 페이드아웃 |
| `Esc` | 전체 즉시 정지 (비상용) |
| 오른쪽 카드의 슬라이더 / 페이드 / 정지 | 재생 중인 큐 하나만 조절 (페이드는 선택한 시간 적용) |

GO를 연달아 두 번 눌러도 한 번만 실행됩니다(0.25초 이중 입력 방지).

## 2. 큐 구성 (2026.11.14 수정, 총 16개)

| 큐 | 장 | GO 타이밍 | 소리 |
| --- | --- | --- | --- |
| 0 | 프리쇼 | 관객 입장 시간 | 시작 음악: 으스스한 저승관리청 약 5분 |
| 1 | 1장 | 지문 '휴대전화 벨소리.' | 전화벨 수신 (3번, 7초) |
| 1B | 1장 | "여보세요?" 받는 순간 | 전화벨 정지 |
| 1C | 1장 | 1B 바로 뒤 | 녹음 음성 1-1 (큐프1 새 녹음 0.5–6.5초, 6초) |
| 1D | 1장 | 1C 뒤 다음 대사 차례 | 녹음 음성 1-2 (6–14.5초, 8.5초) |
| 1E | 1장 | 1D 뒤 다음 대사 차례 | 녹음 음성 1-3 (14.5–22.5초, 8초) · 22.5초 이후는 쓰지 않음 |
| 2 | 1장 | 지문 '(전화 종료)' | 전화 끊김 (통화 종료음) |
| 3 | 2장 | '팀장이 휴대전화를 꺼내 감사팀장에게 전화를 한다.' | 감사팀장 전화 신호, 발신음 (6초) |
| 3B | 2장 | "감사팀장님 오랜만이에요." 직전 | 신호 정지 |
| 3C | 2장 | 3B 바로 뒤 | 녹음 음성 2 (큐프2, 10초) |
| 4 | 4장 | 지문 '그때 휴대전화 벨소리.' | 벨소리, 인사과 전화, 크게 (2번, 5초) |
| 4A | 4장 | 4와 4B 사이 | 벨소리 2번(5초) + 녹음 음성 3 (큐프3), 31초 — 시작할 때 4번 벨소리는 끊기고 녹음 속 벨소리로 이어짐 |
| 4B | 4장 | "(전화 받음.) 여보세요?" | 벨소리 정지 (녹음 3은 계속) |
| 5 | 8장 | "(방송) 긴급 공지입니다…" 직전 | 긴급공지 방송 차임 |
| 5B | 8장 | 5 끝나면 바로 | 녹음 음성 4 · 긴급공지 방송 (큐프4, 8초) |
| 6 | 엔딩 | '밝은 음악. 모두 관객을 향해 인사한다.' | 엔딩 밝은 음악 (커튼콜) 약 3분 |

**0번 시작 음악(약 5분 4초)** 은 처음부터 끝까지 으스스합니다. 음이 나간 오르골 로비 왈츠(낮은 현 클러스터·바람·삐걱임) → 저승 오피스 왈츠(D단조, 첼레스타·오르골 선율, 테레민, 시계 소리) → 삼도천 지하철(낮은 드론, 철길 리듬) → 더 낮고 느린 로비 왈츠 순서이고, 한 번 재생하면 끝납니다. 공연이 시작되면 1번 벨소리 큐가 1초에 걸쳐 끄거나, 그 전에 `F`로 페이드합니다.

**6번 엔딩 음악(약 3분 5초)** 은 커튼콜 주제를 C → D → E장조로 올려 가며 반복합니다. 가볍게 시작해 풀 밴드, 브라스, 중간 브레이크(손뼉·플루트)를 거쳐 마지막에 큰 화음으로 끝납니다. 인사가 일찍 끝나면 `F`(5초나 10초)로 정리합니다.

- **반복 재생은 없습니다.** 모든 큐는 한 번 재생하고 끝납니다. 정지 큐로 그 전에 끌 수 있습니다.
- **정지 큐**(1B, 3B, 4B)는 자기 전화 소리(1, 3, 4번)만 끕니다. 녹음 음성은 끝까지 재생됩니다.
- **녹음 음성**(1C–1E, 3C, 4A, 5B)은 배우가 녹음한 파일입니다. 앞뒤 무음을 잘라 내고 음량을 맞췄고(-16 LUFS), 원본은 `audio/voice_src/`에 있습니다. 한 번 재생되고 끝나면 저절로 사라집니다. **녹음은 페이드되지 않습니다**: `F`(전체 페이드)나 앞 소리를 끄는 큐(1·6)에도 끝까지 재생되고, 끄려면 `Esc`·전체 정지·카드의 "정지"(즉시)를 씁니다. 파일에도 페이드 인·아웃을 넣지 않았습니다.
- **음성 대사**: 인사담당자의 (전화)·(방송) 대사는 배우가 무대 뒤 마이크로 하고, 믹서에서 전화·확성기 음색 EQ(저음·고음 컷)를 겁니다.
- 빠진 큐(오피스 왈츠 단독, 밝은 오프닝, 녹음 메시지, 명부 스팅, 4장 전환, 퇴장 음악)는 git 기록 `b1bd4dc`에 남아 있고, 함수는 `tools/render_cues.py`에 그대로 있습니다.
- 이전 34큐 버전(공포 스팅, 감성 테마 등)은 git 기록 `c0e548c`에 남아 있습니다.

## 4. 음원 바꾸기 (무료 음원 사용)

기본 음원은 이 패키지에서 직접 작곡하고 실제 악기 샘플(FluidR3 GM, MIT 라이선스)로 렌더링했습니다. 효과음은 Python으로 합성했습니다. 그대로 공연해도 저작권 문제가 없습니다.

더 사실적인 녹음을 쓰고 싶다면 다음 순서로 바꾸세요.

1. 아래 사이트에서 음원을 내려받습니다.
2. `audio/` 폴더에 **같은 파일 이름**으로 덮어씁니다. 확장자가 다르면 `cues.js`의 `src`도 고칩니다.
3. 플레이어를 새로고침합니다. 길이는 자동으로 다시 표시됩니다.

| 사이트 | 이용 조건 (2026년 11월 확인) |
| --- | --- |
| [Pixabay 효과음·음악](https://pixabay.com/sound-effects/) | 상업·비상업 모두 무료, 출처 표시 불필요. 단, 음원 자체를 따로 재배포하는 것은 금지 ([FAQ](https://pixabay.com/service/faq/)) |
| [Freesound](https://freesound.org) | 음원마다 라이선스가 다름. 검색 필터에서 **CC0**를 고르면 조건 없이 사용 가능. CC-BY는 출처 표시, NC는 비상업만 허용 |
| [공유마당 (한국저작권위원회)](https://gongu.copyright.or.kr/gongu/main/contents.do?menuNo=200196) | 자유이용·CCL·공공누리 등 음원마다 조건이 다르므로 상세 페이지의 라이선스를 확인. 문의: 저작권상담센터 1800-5455 |

## 5. 음원 다시 만들기 (Python)

음색·템포·길이를 고치려면 `tools/render_cues.py`의 해당 함수를 수정하고 다시 렌더링합니다. 예를 들어 오프닝은 `opening()`, 감성 테마는 `piano_theme()`입니다.

```bash
# Ubuntu/Debian
sudo apt install fluidsynth fluid-soundfont-gm ffmpeg
pip install numpy scipy mido
python3 tools/render_cues.py
```

Windows나 macOS에서는 FluidSynth와 ffmpeg를 설치하고, `FluidR3_GM.sf2`를 `tools/` 폴더에 넣으면 됩니다. 큐 목록(`cues.js`)도 함께 다시 만들어지므로, 손으로 고친 볼륨 값은 렌더 후 다시 확인하세요.

## 6. ML 모델로 생성하기 (선택)

`tools/generate_ml.py`는 Meta의 MusicGen(음악)과 AudioGen(효과음)으로 큐마다 맞춘 프롬프트의 음원을 생성합니다. 결과는 `audio_ml/`에 저장되고, `--apply`를 주면 플레이어가 그 음원을 씁니다.

```bash
pip install torch torchaudio transformers scipy numpy audiocraft
python tools/generate_ml.py --only 1 17 27 --apply   # 원하는 큐만 생성 후 적용
```

- 인터넷이 되는 PC에서 실행해야 합니다. 첫 실행 때 모델을 내려받습니다.
- GPU가 있으면 큐당 수십 초, CPU만 있으면 수 분이 걸립니다.
- 실행할 때마다 결과가 다르므로, 마음에 들 때까지 `--only`로 다시 돌려 고르세요.
- 원래 음원으로 되돌리려면 `cues_original.js`를 `cues.js`로 복사하면 됩니다.
- **라이선스 주의:** MusicGen·AudioGen 가중치는 [CC-BY-NC 4.0(비상업)](https://facebookresearch.github.io/audiocraft/model_cards/MUSICGEN_MODEL_CARD.html)입니다. 유료 공연이라면 기본 음원이나 Pixabay 음원을 쓰세요.
