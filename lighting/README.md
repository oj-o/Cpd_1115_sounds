# 조명 큐 — MA dot2 자동 입력

dot2는 텍스트나 XML 파일로 쇼를 불러오는 기능이 없습니다. 그래서 이 폴더의 스크립트가 **노트북의 dot2 onPC 명령줄에 명령을 대신 입력**해 쇼를 만들고, 그 **쇼 파일을 USB로 콘솔(dot2 core)에 옮기는** 방식으로 진행합니다.

```
lighting/
├─ cues.csv                      ← ★ 조명 큐 (엑셀로 열어 고치는 파일)
├─ patch.csv                     ← 장비 ID와 DMX 주소
├─ groups.csv                    ← 그룹 번호·이름·장비 선택
├─ presets.csv                   ← 프리셋 이름 ↔ dot2 프리셋 번호
├─ dot2_cues.py                  ← 큐 파일 생성기 + dot2 자동 입력기
├─ dot2_commands.txt             ← 생성됨: dot2 명령 전체 목록 (손으로 입력할 때도 사용)
├─ cue_sheet.html                ← 생성됨: 인쇄용 조명 큐시트 (A4 가로)
├─ 0_큐파일_만들기.bat
├─ 1_패치_그룹_자동입력.bat
└─ 2_큐_자동입력.bat
```

큐는 `cues.csv`에 들어 있고, 처음 내용은 조명 큐 문서(대본 빨간 원 기준)와 같습니다. 공연 전 하우스 상태용으로 큐 0.5(Preshow)를 하나 더 넣었습니다.

## 준비물

- Windows 노트북에 **dot2 onPC**를 설치합니다. 버전은 극장 콘솔(dot2 core 2대, fader wing 2대, 2048ch = 4유니버스)과 같게 맞춥니다. 버전이 다르면 쇼 파일을 열지 못할 수 있습니다.
- **Python 3**를 설치합니다. 설치 화면에서 "Add Python to PATH"를 체크하세요. 추가 패키지는 필요 없습니다.
- 이 `lighting` 폴더를 노트북에 복사합니다.

## 진행 순서 (약 30분)

### 1. 새 쇼 만들기
dot2 onPC를 켜고 Backup → **New Show**로 빈 쇼를 엽니다. 이미 내용이 있는 쇼에서 돌리면 저장 방식 확인 창이 떠서 입력이 엉킵니다.

### 2. 장비 추가 (손으로, 약 5분)
Setup → Patch & Fixture Schedule → **Add New Fixtures**에서 아래 묶음을 차례로 추가합니다. **Patch(DMX 주소) 칸은 비워 두세요.** 주소는 다음 단계에서 스크립트가 넣습니다.

| 묶음 | Fixture Type | 수량 | 시작 ID | 이름 |
| --- | --- | --- | --- | --- |
| 1 | Prolights Diamond19 (모드는 19ch 이하) | 10 | 101 | Wash |
| 2 | Chauvet Rogue R2X Spot (모드는 18ch 이하) | 8 | 201 | Spot |
| 3 | LED 파 3ch (Generic RGB, 극장 장비표상 EK light ORB-300으로 추정) | 5 | 301 | LED |
| 4 | Dimmer | 5 | 306 | BG1ch |
| 5 | Dimmer | 6 | 1 | S1 |
| 6 | Dimmer | 12 | 13 | S2S3 |
| 7 | Dimmer | 1 | 26 | S4 |
| 8 | Dimmer | 2 | 28 | S4 |
| 9 | Dimmer | 6 | 32 | S5S6 |
| 10 | Dimmer (블라인더 4구 650W, 디머 구동) | 4 | 401 | Blinder |
| 11 | Dimmer | 1 | 501 | Fog |
| 12 | Dimmer | 9 | 601 | HouseLED |
| 13 | Dimmer | 6 | 611 | HouseDim |

모드를 고를 때는 채널 수가 도면의 주소 간격보다 크지 않은 것을 고릅니다. Diamond19는 19ch 이하, Rogue는 18ch 이하입니다.

### 3. 1단계 자동 입력: 패치 주소와 그룹 (약 2분)
1. `1_패치_그룹_자동입력.bat`을 더블클릭합니다.
2. 5초 안에 dot2 onPC 화면의 **명령줄(Command Line)을 한 번 클릭**합니다.
3. 자동 입력이 끝나면 Group 풀에서 대수를 확인합니다. 정상이라면 Spot 8, Wash 10, Front 12, Top 6, Back 8, BG 11, Blinder 4, House 15, Fog 1, Spot Solo 1, Spot Pair 2입니다.
4. Patch 창에서 주소도 확인합니다. 블라인더(401~404)는 디머(Sensor3)로 켜는 재래식 장비인데 회로 번호가 도면에 없어 비워 두었습니다. 극장에서 회로를 확인한 뒤 `Assign Fixture 401 At DMX 1.(회로번호)` 형식으로 4대를 패치하세요.
5. 끝나면 **Clear를 두 번** 눌러 선택과 값을 지웁니다.

### 4. 프리셋 9개 저장 (손으로, 약 10분)
색과 위치는 엔코더로만 정할 수 있어서 자동으로 넣을 수 없습니다. 아래 번호에 **정확히** 저장하세요. 색 프리셋은 Spot·Wash·BG 그룹을 함께 선택한 상태에서 저장해야 어느 그룹에서 불러도 적용됩니다.

| 프리셋 | 이름 | 내용 |
| --- | --- | --- |
| 4.1 | Office | 차가운 화이트 + 연보라 |
| 4.2 | Meeting | 회의실 웜 화이트 |
| 4.3 | Amber | 앰버 |
| 4.4 | Blue | 배경 블루 |
| 4.5 | Curtain | 커튼콜 멀티 컬러 |
| 2.1 | DownC | 다운센터 독백 (Spot) |
| 2.2 | Desk | 주인공 책상 (Spot Solo = 202) |
| 2.3 | Audit | 감사팀장 자리 (Spot Pair = 205, 208) |
| 2.4 | Sweep | 커튼콜 객석 쪽 (Spot) |

위치는 노트북에서 대략 잡아 두고, 극장에서 실제 무대를 보며 다듬으면 됩니다. 프리셋만 고치면 큐 전체에 반영됩니다.

### 5. 2단계 자동 입력: 큐 (약 5분)
`2_큐_자동입력.bat`을 더블클릭하고, 1단계처럼 명령줄을 클릭합니다. 큐 0.5~14와 12.5가 만들어지고 이름과 페이드 시간이 들어갑니다.

### 6. 마무리
- Cues 창에서 **큐 12.5의 Trig를 Follow**로 바꿉니다. 그러면 블라인더 1초 뒤 자동으로 암전됩니다. 명령줄로는 바꿀 수 없어 손으로 해야 합니다.
- 큐를 한 번씩 넘겨 보며 확인합니다.
- Backup → **Save Show As**로 저장합니다(예: `Jeoseung_1115`). USB를 꽂고 USB에도 저장합니다.

### 7. 콘솔로 옮기기
USB를 dot2 core에 꽂고 Backup → **Load Show**에서 쇼를 엽니다. 극장에서 블라인더 주소를 패치하고 위치 프리셋을 다듬은 뒤 다시 저장합니다.

## 문제가 생기면

| 증상 | 해결 |
| --- | --- |
| 명령에 한글이 섞여 들어감 | 한/영 키로 영문 상태로 바꾼 뒤 다시 실행 |
| 글자가 빠짐 | `python dot2_cues.py type 2 --delay 0.06` 처럼 간격을 늘려 실행 |
| 중간에 멈추고 싶음 | 마우스를 화면 왼쪽 위 모서리로 옮김. 화면에 나온 `--from` 번호로 이어서 실행 |
| 저장 방식 확인 창이 뜸 | 이미 있는 그룹·큐에 저장하려는 경우. 새 쇼에서 다시 시작하거나, 그 줄 다음 번호부터 `--from`으로 이어서 실행 |
| 그룹 대수가 다름 | 그룹이 섞인 경우. 해당 그룹을 지우고 `dot2_commands.txt`의 그 부분만 손으로 입력 |

자동 입력이 안 되는 환경이면 `dot2_commands.txt`를 보며 콘솔에서 직접 입력해도 같은 결과가 나옵니다. 키보드를 dot2 core에 USB로 연결하면 빠르게 칠 수 있습니다.

## 큐 바꾸기 (cues.csv)

1. `cues.csv`를 엑셀로 엽니다. 한 줄이 큐 하나입니다.
2. 값을 고치거나 줄을 넣고 지웁니다.
3. 저장할 때 형식은 **CSV UTF-8(쉼표로 분리)** 을 고릅니다. 일반 CSV로 저장해도 읽히지만 UTF-8이 가장 안전합니다.
4. `0_큐파일_만들기.bat`을 더블클릭합니다. 파일을 검사한 뒤 `dot2_commands.txt`와 `cue_sheet.html`을 새로 만들고, 큐시트를 브라우저로 엽니다.
5. dot2에 넣을 때는 **새 쇼**에서 진행 순서 1~6단계를 다시 합니다. 1·2번 bat도 고친 CSV를 그대로 따라갑니다.

| 열 | 쓰는 법 |
| --- | --- |
| 큐 | 숫자. 위에서 아래로 커져야 함 (0.5, 1, 2, 2.5 …) |
| 이름 | dot2에 들어가는 큐 이름. **영문·숫자·공백·`.` `-` `+`만** (한글은 자동 입력이 안 됨) |
| 대본표시, GO 타이밍, 메모 | 큐시트에만 나오는 설명. 한글 자유 |
| Fade | 페이드 시간(초) |
| Trig | `Go` 또는 `Follow`. Follow는 dot2에서 손으로 바꿔야 하며, 큐시트에 노란 줄로 표시됨 |
| 음향 | 같은 순간에 나가는 음향 큐 번호 (큐시트 표시용) |
| Spot, Wash, Front, Top, Back, BG, Blinder, House | 그룹 레벨 0~100. **빈칸은 0** (매 큐마다 모두 명시해 앞 큐 값이 남지 않음) |
| Spot Solo, Spot Pair | Spot의 일부만 따로 켤 때 레벨. **빈칸은 손대지 않음** |
| ○○ 색, ○○ 위치 | `presets.csv`의 프리셋 이름 (Office, Amber, Desk …). 빈칸은 앞 큐 상태 유지 |

- **새 프리셋**은 `presets.csv`에 이름·번호를 더하고, dot2에서도 그 번호에 저장합니다.
- **새 그룹**은 `groups.csv`에 한 줄 더하고, `cues.csv`에 그 그룹 이름으로 열을 만듭니다. 그룹의 색·위치를 쓰려면 `그룹이름 색`, `그룹이름 위치` 열을 만듭니다. "매 큐 0으로 초기화" 칸에 O를 넣으면 빈칸을 0으로 처리합니다.
- **주소 변경**은 `patch.csv`의 DMX 칸을 고칩니다. 비우면 패치하지 않습니다.

생성기가 잘못 쓴 곳을 찾아 줄 번호와 함께 알려 주고, 고칠 때까지 파일을 만들지 않습니다.
- 레벨이 0~100을 벗어남
- 없는 프리셋 이름
- 한글 큐 이름
- 큐 번호 중복이나 순서 뒤바뀜
- DMX 주소 겹침
- 그룹 대수가 patch.csv와 다름

맥이나 리눅스에서는 `python3 dot2_cues.py build`로 같은 파일을 만들 수 있습니다. 자동 입력만 Windows가 필요합니다.
