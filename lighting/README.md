# 조명 큐 — MA dot2 자동 입력

dot2는 텍스트나 XML 파일로 쇼를 불러오는 기능이 없습니다. 그래서 이 폴더의 스크립트가 **노트북의 dot2 onPC 명령줄에 명령을 대신 입력**해 쇼를 만들고, 그 **쇼 파일을 USB로 콘솔(dot2 core)에 옮기는** 방식으로 진행합니다.

```
lighting/
├─ cue_maker.html               ← 웹 조명 큐 생성 페이지 (음향 큐 화면 우측 하단 '💡 조명 큐 생성' 버튼) + 비상 수동 조정
├─ cues.csv                      ← ★ 조명 큐 (엑셀로 열어 '명령' 칸을 고치는 파일)
├─ looks.csv                     ← 자주 쓰는 룩 A~F (명령 묶음)
├─ patch.csv                     ← 장비 ID와 DMX 주소
├─ groups.csv                    ← 그룹 번호·이름·장비 선택
├─ presets.csv                   ← 프리셋 이름 ↔ dot2 프리셋 번호
├─ dot2_cues.py                  ← 큐 파일 생성기 + dot2 자동 입력기
├─ dot2_looks.txt                ← 생성됨: 큐 없이 수동 운용할 때 룩 페이더 L1~L10에 넣을 명령
├─ dot2_commands.txt             ← 생성됨: dot2 명령 전체 목록 (손으로 입력할 때도 사용)
├─ cue_sheet.html                ← 생성됨: 인쇄용 조명 큐시트 (A4 가로)
├─ 0_큐파일_만들기.bat
├─ 1_패치_그룹_자동입력.bat
├─ 2_큐_자동입력.bat
└─ 3_쇼파일_한번에_만들기.bat    ← 1단계 → 프리셋 대기 → 2단계 → 저장 안내를 한 번에
```

큐는 `cues.csv`에 들어 있습니다. 2026.11.14 조명 순서 메모(대본 2_1 PDF 메모) 기준으로 큐 0.5~26, 모두 27개입니다. 장마다 '암전 → 동작 → 조명 서서히' 순서로 짜여 있습니다.

## 웹에서 큐 파일 만들기 (cue_maker.html)

음향 큐 화면(https://oj-o.github.io/Cpd_1115_sounds/) **우측 하단의 '💡 조명 큐 생성' 버튼**을 누르면 새 탭으로 열립니다. 폴더에서 `lighting/cue_maker.html`을 더블클릭해도 됩니다.

- 조명 순서 메모(노란 글씨: '암전 → 동작 → 조명 서서히' 등) 아래에 그 장면의 큐가 나옵니다.
- **체크한 큐만 큐 파일에 들어갑니다.** '메모 큐만'을 누르면 메모에 적힌 큐만 남고, 메모에 없는 프리쇼(0.5)·하우스 인(26)은 빠집니다.
- 이름·Fade·명령 등을 고치면 아래 결과 줄(어느 그룹이 몇 %인지)과 오류가 바로 보입니다. 편집은 그 브라우저에 자동 저장되고, '원래대로'로 저장소 cues.csv 상태로 돌아갑니다.
- **큐 파일 저장 (cues.csv)** → 받은 파일을 이 폴더의 `cues.csv`에 덮어쓰고 `0_큐파일_만들기.bat` → `2_큐_자동입력.bat`.
- 오른쪽 아래 '2단계 명령 미리보기'는 dot2_commands.txt의 큐 부분과 같은 명령입니다. 손으로 입력할 때 복사하거나 txt로 저장합니다.

## 큐 없이 콘솔에서 수동 운용

큐 리스트를 쓰지 않고 **룩 페이더**를 손으로 올리고 내려 공연을 운용하는 방법입니다. 노트북이나 자동 입력이 없어도 콘솔만으로 됩니다.

1. **준비 (한 번, 약 15분)**: `dot2_looks.txt`의 룩 10개를 fader wing의 빈 페이더 L1~L10에 저장합니다. 룩마다 `Clear` 두 번 → 적힌 줄을 차례로 입력(각 줄 끝 `Please`) → `Store` → 그 페이더의 버튼 → `Clear` 두 번. 페이더에 룩 이름 라벨을 붙여 둡니다. 페이더 순서는 공연에 처음 나오는 순서입니다 (L1 S, L2 A, L3 I, L4 B, L5 P, L6 W, L7 C, L8 T, L9 E, L10 F).
2. **운용**: 아래 표대로 페이더를 올리고 내립니다. 페이드 시간은 페이더를 움직이는 속도입니다. 암전 = 올라가 있는 페이더를 내림, 컷 = 빠르게 내림. 장면을 바꿀 때는 다음 페이더를 올린 뒤 이전 페이더를 내립니다.
3. **같이 쓰지 않기**: 수동 운용 중에는 Main Executor의 GO를 누르지 않습니다(큐와 섞임). 수동으로 넣은 값이 프로그래머에 남지 않게 `Clear` 두 번.

## 유사시 수동 조정 (공연 중 비상)

큐가 꼬이거나 조명이 잘못 나갈 때 쓰는 방법입니다. cue_maker.html 오른쪽 **⚠ 비상 수동 조정** 칸에서 그룹·레벨·큐를 고르면 입력할 명령이 크게 나오고, '비상 카드 인쇄'로 한 장짜리 카드를 뽑아 콘솔 옆에 둘 수 있습니다.

원리: dot2에서 손으로 넣은 값(프로그래머)은 재생 중인 큐보다 우선합니다. 그래서 수동으로 덮어쓰고, **Clear**로 지우면 원래 큐 상태로 돌아갑니다. 큐 리스트 자체는 바뀌지 않습니다(Store만 하지 않으면 됨).

| 상황 | 콘솔에서 | 비고 |
| --- | --- | --- |
| 큐를 잘못 넘김 / 건너뜀 | `Goto Cue 12` Enter | 그 큐로 바로 이동 (그 큐의 Fade로). 한 칸 뒤로는 **Go−** 키 |
| GO를 너무 일찍 누름 | **Pause** 키 → 타이밍에 **Go** | 진행 중인 페이드가 멈춤 |
| 특정 그룹만 너무 밝음·어두움 | `Group 3 At 50` Enter | 그룹 번호는 아래 표. 휠(Dimmer 인코더)로 미세 조정 가능 |
| 배우가 어둠 속에 있음 | `Group 3 At 80` Enter | Front 80% |
| 무대를 일단 밝게 | `Group 3 + 4 + 2 At 70` Enter | Front·Top·Wash 70% |
| 객석등이 필요함 | 페이더 1 올림, 또는 `Group 8 At 100` Enter | House |
| 수동 값을 풀고 큐로 복귀 | **Clear** 3번 | 1번: 선택 해제, 2번: 값 해제, 3번: 전부 해제 |
| 순간적으로 전부 꺼야 함 | **B.O.** 누르고 있기 | 누르는 동안만 전체 0. 길게 끌 때는 `Goto Cue`로 암전 큐(예: 1, 4)로 |
| 콘솔이 멈춤 | 객석등·작업등 벽 스위치, 무대감독 무전 | 재부팅 후 쇼를 열고 `Goto Cue 번호`로 이어서 |

그룹 번호: 1 Spot · 2 Wash · 3 Front · 4 Top · 5 Back · 6 BG · 7 Blinder · 8 House · 9 Fog · 10 Spot Solo · 11 Spot Pair

주의: 수동 조정 중에 **Store를 누르지 마세요.** 수동 값이 큐에 저장됩니다. 끝나면 꼭 Clear 3번으로 돌려놓고 다음 큐를 GO 합니다.

## 준비물

- Windows 노트북에 **dot2 onPC**를 설치합니다. 버전은 극장 콘솔(dot2 core 2대, fader wing 2대, 2048ch = 4유니버스)과 같게 맞춥니다. 버전이 다르면 쇼 파일을 열지 못할 수 있습니다.
- **Python 3**를 설치합니다. 설치 화면에서 "Add Python to PATH"를 체크하세요. 추가 패키지는 필요 없습니다.
- 이 `lighting` 폴더를 노트북에 복사합니다.

## 진행 순서 (약 30분)

> 3~5단계는 `3_쇼파일_한번에_만들기.bat` 하나로 이어서 할 수 있습니다. 중간에 프리셋을 저장할 때만 멈추고 Enter를 기다립니다.
>
> 쇼 파일(.backup)을 파이썬이 직접 쓰지 않는 이유: dot2 쇼 파일 형식은 공개되지 않았고, dot2에는 텍스트·XML 가져오기 메뉴가 없습니다. 잘못 만든 파일은 콘솔에서 열리지 않거나 쇼를 망가뜨릴 수 있어, dot2가 직접 저장하게 합니다.

### 1. 새 쇼 만들기
dot2 onPC를 켜고 Backup → **New Show**로 빈 쇼를 엽니다. 이미 내용이 있는 쇼에서 돌리면 저장 방식 확인 창이 떠서 입력이 엉킵니다.

### 2. 장비 추가 (손으로, 약 5분)
Setup → Patch & Fixture Schedule → **Add New Fixtures**에서 아래 묶음을 차례로 추가합니다. **Patch(DMX 주소) 칸은 비워 두세요.** 주소는 다음 단계에서 스크립트가 넣습니다.

| 묶음 | Fixture Type | 수량 | 시작 ID | 이름 |
| --- | --- | --- | --- | --- |
| 1 | Prolights Diamond19 (모드는 19ch 이하) | 10 | 101 | Wash |
| 2 | Chauvet Rogue R2X Spot (모드는 18ch 이하) | 8 | 201 | Spot |
| 3 | LED 파 3ch (Generic RGB, 극장 장비표상 EK light ORB-300으로 추정) | 5 | 301 | LED |
| 4 | Dimmer | 5 | 306 | BG1ch |
| 5 | Dimmer | 6 | 1 | S1 |
| 6 | Dimmer | 12 | 13 | S2S3 |
| 7 | Dimmer | 1 | 26 | S4 |
| 8 | Dimmer | 2 | 28 | S4 |
| 9 | Dimmer | 6 | 32 | S5S6 |
| 10 | Dimmer (블라인더 4구 650W, 디머 구동) | 4 | 401 | Blinder |
| 11 | Dimmer | 1 | 501 | Fog |
| 12 | Dimmer | 9 | 601 | HouseLED |
| 13 | Dimmer | 6 | 611 | HouseDim |

모드를 고를 때는 채널 수가 도면의 주소 간격보다 크지 않은 것을 고릅니다. Diamond19는 19ch 이하, Rogue는 18ch 이하입니다.

### 3. 1단계 자동 입력: 패치 주소와 그룹 (약 2분)
1. `1_패치_그룹_자동입력.bat`을 더블클릭합니다.
2. 5초 안에 dot2 onPC 화면의 **명령줄(Command Line)을 한 번 클릭**합니다.
3. 자동 입력이 끝나면 Group 풀에서 대수를 확인합니다. 정상이라면 Spot 8, Wash 10, Front 12, Top 6, Back 8, BG 11, Blinder 4, House 15, Fog 1, Spot Solo 1, Spot Pair 2입니다.
4. Patch 창에서 주소도 확인합니다. 블라인더(401~404)는 디머(Sensor3)로 켜는 재래식 장비인데 회로 번호가 도면에 없어 비워 두었습니다. 극장에서 회로를 확인한 뒤 `Assign Fixture 401 At DMX 1.(회로번호)` 형식으로 4대를 패치하세요.
5. 끝나면 **Clear를 두 번** 눌러 선택과 값을 지웁니다.

### 4. 프리셋 10개 저장 (손으로, 약 10분)
dot2 명령줄에는 색·위치 값을 숫자로 넣는 명령이 없어(At은 밝기만 받음) 이 단계만 자동으로 할 수 없습니다. 큐의 `blue`, `desk` 같은 단어는 여기서 저장한 프리셋 번호를 부릅니다. 아래 번호에 **정확히** 저장하세요. 색 프리셋은 Spot·Wash·BG 그룹을 함께 선택한 상태에서 저장해야 어느 그룹에서 불러도 적용됩니다.

| 프리셋 | 이름 | 내용 |
| --- | --- | --- |
| 4.1 | Office | 차가운 화이트 + 연보라 |
| 4.2 | Meeting | 회의실 웜 화이트 |
| 4.3 | Amber | 앰버 |
| 4.4 | Blue | 배경 블루 |
| 4.5 | Curtain | 커튼콜 멀티 컬러 |
| 2.1 | DownC | 다운센터 독백 (Spot) |
| 2.2 | Desk | 주인공 책상 (Spot Solo = 202) |
| 2.3 | Audit | 감사팀장 자리 (Spot Pair = 205, 208) |
| 2.4 | Sweep | 커튼콜 객석 쪽 (Spot) |
| 2.5 | Talk | 8장 저승사자·팀장 혼잣말 자리 (Spot) |

위치는 노트북에서 대략 잡아 두고, 극장에서 실제 무대를 보며 다듬으면 됩니다. 프리셋만 고치면 큐 전체에 반영됩니다.

### 5. 2단계 자동 입력: 큐 (약 5분)
`2_큐_자동입력.bat`을 더블클릭하고, 1단계처럼 명령줄을 클릭합니다. 큐 0.5~26이 만들어지고 이름과 페이드 시간이 들어갑니다.

### 6. 마무리
- 모든 큐가 Trig `Go`(운용자가 GO를 눌러 진행)입니다. Follow 큐를 넣으면 Cues 창에서 손으로 바꿔야 합니다.
- 큐를 한 번씩 넘겨 보며 확인합니다.
- Backup → **Save Show As**로 저장합니다(예: `Jeoseung_1115`). USB를 꽂고 USB에도 저장합니다.

### 7. 콘솔로 옮기기
USB를 dot2 core에 꽂고 Backup → **Load Show**에서 쇼를 엽니다. 극장에서 블라인더 주소를 패치하고 위치 프리셋을 다듬은 뒤 다시 저장합니다.

## 문제가 생기면

| 증상 | 해결 |
| --- | --- |
| 명령에 한글이 섞여 들어감 | 한/영 키로 영문 상태로 바꾼 뒤 다시 실행 |
| 글자가 빠짐 | `python dot2_cues.py type 2 --delay 0.06` 처럼 간격을 늘려 실행 |
| 중간에 멈추고 싶음 | 마우스를 화면 왼쪽 위 모서리로 옮김. 화면에 나온 `--from` 번호로 이어서 실행 |
| 저장 방식 확인 창이 뜸 | 이미 있는 그룹·큐에 저장하려는 경우. 새 쇼에서 다시 시작하거나, 그 줄 다음 번호부터 `--from`으로 이어서 실행 |
| 그룹 대수가 다름 | 그룹이 섞인 경우. 해당 그룹을 지우고 `dot2_commands.txt`의 그 부분만 손으로 입력 |

자동 입력이 안 되는 환경이면 `dot2_commands.txt`를 보며 콘솔에서 직접 입력해도 같은 결과가 나옵니다. 키보드를 dot2 core에 USB로 연결하면 빠르게 칠 수 있습니다.

## 큐 바꾸기 (cues.csv)

1. `cues.csv`를 엑셀로 엽니다. 한 줄이 큐 하나입니다.
2. 값을 고치거나 줄을 넣고 지웁니다.
3. 저장할 때 형식은 **CSV UTF-8(쉼표로 분리)** 을 고릅니다. 일반 CSV로 저장해도 읽히지만 UTF-8이 가장 안전합니다.
4. `0_큐파일_만들기.bat`을 더블클릭합니다. 파일을 검사한 뒤 `dot2_commands.txt`와 `cue_sheet.html`을 새로 만들고, 큐시트를 브라우저로 엽니다.
5. dot2에 넣을 때는 **새 쇼**에서 진행 순서 1~6단계를 다시 합니다. 1·2번 bat도 고친 CSV를 그대로 따라갑니다.

| 열 | 쓰는 법 |
| --- | --- |
| 큐 | 숫자. 위에서 아래로 커져야 함 (0.5, 1, 2, 2.5 …) |
| 이름 | dot2에 들어가는 큐 이름. **영문·숫자·공백·`.` `-` `+`만** |
| 대본표시, GO 타이밍, 메모 | 큐시트에만 나오는 설명. 한글 자유 |
| Fade | 페이드 시간(초) |
| Trig | `Go` 또는 `Follow` (Follow는 dot2에서 손으로 바꿈) |
| 음향 | 같은 순간에 나가는 음향 큐 번호 (큐시트 표시용) |
| **명령** | 이 큐의 조명 상태. 아래 규칙으로 쓰면 프로그램이 그룹 레벨과 프리셋 명령을 자동으로 만듭니다 |

### 명령 쓰는 법

쉼표로 나눠 쓰고, 왼쪽부터 차례로 적용됩니다. 쓰지 않은 그룹은 0(꺼짐)입니다. 대소문자 구분 없고, 한글 별칭도 됩니다.

| 쓰기 | 뜻 |
| --- | --- |
| `off` (`bo`, `암전`) | 전부 끔 |
| `spot on` / `스팟 켬` | Spot 100 |
| `spot off` | Spot 0 |
| `front 70` | Front 70% |
| `all on` / `all 60` | Blinder·House·Fog를 뺀 무대 전체 |
| `bg 30 blue` / `배경 30 블루` | 레벨과 색을 함께 |
| `spot solo 70 amber desk` | 레벨 + 색 + 위치 |
| `blue` (그룹 없이) | 그 시점에 켜진 Spot·Wash·BG(·Solo·Pair)에 색 적용 |
| `A` ~ `F` | looks.csv의 룩. 뒤에 더 쓰면 덮어씀 (예: `A, bg 50`) |
| `house on`, `blinder on` | 하우스, 블라인더 |

예: `A` (사무실), `house on, bg 15 blue` (입장 전), `all on, blinder on` (커튼콜 히트), `스팟 켬, 배경 40 블루, 솔로 80 책상`.

- 그룹 이름·별칭은 `groups.csv`, 프리셋 이름·별칭은 `presets.csv`의 '별칭' 칸(`/`로 구분)에서 더하거나 바꿉니다.
- Front·Top·Back 같은 디머 그룹에 색을 주면 오류로 알려 줍니다(`groups.csv`의 '색·위치' 칸이 O인 그룹만 색·위치를 받음).
- 룩을 고치면(`looks.csv`) 그 룩을 쓰는 큐가 모두 바뀝니다.
- 명령 칸을 비우고 그룹 이름 열(Spot, Wash …)에 숫자를 쓰는 예전 방식도 그대로 읽습니다.

- **새 프리셋**은 `presets.csv`에 이름·번호를 더하고, dot2에서도 그 번호에 저장합니다.
- **새 그룹**은 `groups.csv`에 한 줄 더하고, `cues.csv`에 그 그룹 이름으로 열을 만듭니다. 그룹의 색·위치를 쓰려면 `그룹이름 색`, `그룹이름 위치` 열을 만듭니다. "매 큐 0으로 초기화" 칸에 O를 넣으면 빈칸을 0으로 처리합니다.
- **주소 변경**은 `patch.csv`의 DMX 칸을 고칩니다. 비우면 패치하지 않습니다.

생성기가 잘못 쓴 곳을 찾아 줄 번호와 함께 알려 주고, 고칠 때까지 파일을 만들지 않습니다.
- 레벨이 0~100을 벗어남
- 명령에 모르는 단어, 디머 그룹에 색 지정, 그룹 없이 위치만 씀
- 없는 프리셋 이름
- 한글 큐 이름
- 큐 번호 중복이나 순서 뒤바뀜
- DMX 주소 겹침
- 그룹 대수가 patch.csv와 다름

맥이나 리눅스에서는 `python3 dot2_cues.py build`로 같은 파일을 만들 수 있습니다. 자동 입력만 Windows가 필요합니다.
